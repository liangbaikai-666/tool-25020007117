## 1. 在常用软件中启用 Vim mode
- **Bash**：`~/.bashrc` 加 `set -o vi`
- **Zsh**：`~/.zshrc` 加 `bindkey -v`
- **Fish**：`~/.config/fish/config.fish` 加 `fish_vi_key_bindings`
- **Readline 程序**（Python REPL、irb 等）：`~/.inputrc` 加
  ini

set editing-mode vi

set keymap vi-insert

- **Git 提交/ rebase 编辑器**：`git config --global core.editor "vim"`
- **VS Code**：装 `VSCodeVim`；可选 `settings.json` 开
  `"vim.useSystemClipboard": true`
- **JetBrains**：装 `IdeaVim`
- **Xcode**：Editor 菜单原生可开 Vim Mode
- **Qt Creator**：Preferences → FakeVim
- **浏览器**：Chrome 装 `Vimium`，Firefox 装 `Tridactyl`

## 2. 一个月只走 Vim mode
- 日常写笔记、改配置、写代码全用普通模式优先：
  `h j k l` 移动，`w b e` 跳词，`ciw` `ci"` `di(` 改/删文本对象，
  `yy` `p` `>` `.` `;` 复用上次操作。
- 觉得卡就搜：“vim how to …”，例如：
- “move to next occurrence” → `f{char}` / `t{char}` / `*`
- “edit in column” → `Ctrl-v` 块选择
- “repeat complex edit” → `qa ... q` 然后 `@a`
