# 命令行练习解答

## 1. `--` 的作用与文件操作

**`--` 的作用：**
`--` 是“选项终止符”。它告诉命令解析器：后面的内容都作为普通参数（如文件名），不再解析为选项或 flag。

**创建与删除：**
- 创建：`touch -- -myfile`
- 不使用 `--` 删除：`rm ./-myfile`（通过添加 `./` 路径前缀，避免 `-` 被解析为选项）

## 2. `ls` 命令

**命令：**
bash

ls -lath --color=auto

**参数说明：**
| 参数                  | 含义              |
| --------------------- | ----------------- |
| `-l`                  | 长格式显示        |
| `-a`                  | 包含隐藏文件      |
| `-h`                  | 易读大小（K/M/G） |
| `-t`                  | 按修改时间排序    |
| `--color=auto` / `-G` | 输出带颜色        |

## 3. 进程替换与 `diff` 比较

**命令：**
bash

diff <(printenv | sort) <(export | sort)

**输出不同的原因：**
1. **格式不同**：`export` 输出带有 `export ` 前缀（如 `export KEY=value`），而 `printenv` 仅输出 `KEY=value`
2. **内容范围不同**：`export` 可能包含 Shell 函数等额外信息，而 `printenv` 只包含环境变量
3. **命令性质不同**：`export` 是 Shell 内建命令，`printenv` 是外部程序，两者获取信息的方式有差异
